## Install

```bash
pip install c3-cli
```

## Configure

```bash
c3 configure
```

Or set environment variable:

```bash
export C3_API_KEY=your_key
```

Get your API key at [console.compute3.ai](https://console.compute3.ai).

## Commands

```bash
c3 --help

# Configuration
c3 configure              # Set up API key

# Billing
c3 billing balance        # Check balance
c3 billing transactions   # List transactions

# GPU Instances
c3 instances list         # List available GPUs with pricing
c3 instances gpus         # List GPU types
c3 instances regions      # List regions
c3 instances launch       # Launch instance

# Jobs
c3 jobs list              # List jobs
c3 jobs create            # Create job
c3 jobs logs              # Get logs
c3 jobs metrics           # Get GPU metrics
c3 jobs cancel            # Cancel job

# ComfyUI
c3 comfyui templates      # List workflow templates
c3 comfyui run            # Run ComfyUI workflow

# LLM
c3 llm models             # List LLM models
c3 llm chat               # Chat with LLM

# User
c3 user                   # Get user info
```

## Output Formats

Most commands support `-o json` for JSON output:

```bash
c3 billing balance -o json
c3 jobs list -o json
c3 instances list -o json
```

## Quick Examples

### Check Balance

```bash
c3 billing balance
```

### Launch GPU Instance

```bash
# Simple launch
c3 instances launch nvidia/cuda:12.0 -g l40s

# With command and logs
c3 instances launch my-image:latest -g h100 -c "python train.py" -f
```

### Generate Image with ComfyUI

```bash
c3 comfyui run flux_schnell --prompt "a sunset over mountains" --output sunset
```

### Chat with LLM

```bash
c3 llm chat deepseek-v3.1 "Hello!"
```

## Global Options

| Option | Description |
|--------|-------------|
| `--help` | Show help for any command |
| `-o json` | JSON output (most commands) |
